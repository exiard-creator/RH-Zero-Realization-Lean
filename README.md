# RH-Zero-Realization-Lean

リーマン予想に関連する「Zero-Inaccessible Realization and Isometric Theta-Profile Exchange」の論理部分を Lean 4 で形式化するためのリポジトリです。

## 現在の内容

- `RHZeroRealization.lean`：形式的なゼロ、臨界軸上の点、等長交換可能性を抽象化し、それらの関係から導ける論理的な定理を記述します。
- Lean 4 の標準機能のみを使用し、現時点で Mathlib には依存しません。

## 重要な範囲・制限

**このファイルはリーマン予想の完全な形式証明ではありません。**

`Spec` 構造体のフィールド `exchange_iff_axis` は、「等長交換可能であること」と「臨界軸上にあること」が同値である、という数学的結果を前提として受け取ります。この同値性の解析学的証明、完成ゼータ関数の構成、テータ積分との関係は、この Lean ファイルでは形式化されていません。

したがって、このファイルが証明しているのは、上記の前提を置いた場合に、普遍的なゼロ実現性から臨界軸上への帰結が論理的に導かれることなどです。前提そのものの正しさを Lean が検証したわけではありません。

ソースに `axiom`、`sorry`、`admit` という記述がないことだけをもって、リーマン予想の証明が完成しているとは判断できません。構造体のフィールドとして与えた前提も、検証範囲を評価する際には明示的に扱う必要があります。

## ローカルでの検証

Lean 4 と Lake をインストールした環境で、リポジトリのルートから実行します。

```sh
lake build
```

このリポジトリは GitHub Actions を使用しません。ビルドと検証はローカルで行います。
